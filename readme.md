Circle Packing
==============

Rust libraries for circle/ellipse geometry and circle packing solvers.

## Layout

```text
projects/
  crates/
    circle/            # circle and ellipse geometry
    circle-packing/    # circle packing problem solver
  packages/
    homepage/          # demo site (VMZ host shell)
```

## Build

```bash
cargo test --release
# or: pnpm test
```

## Web

```bash
pnpm dev:web
```
